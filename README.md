# Farmai

Private project repository.

## Working from a phone

This repo is set up to be worked on remotely (e.g. from a phone) using Claude Code.
See the workflow:

1. A machine (home PC or VPS) runs Claude Code and has this repo cloned.
2. Connect to that machine from the phone over SSH (Tailscale recommended for secure access).
3. Run `claude` inside the repo and work as normal.
4. Commit and push changes back to GitHub.

Alternative: open this repo in **GitHub Codespaces** from the phone browser and run Claude Code there — no always-on PC required.
